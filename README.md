# AI Assistance

AI Assistance is an AI-based application that provides intelligent responses to user queries using the OpenAI API.

## Features

- AI-powered question answering
- User-friendly interface
- Flask-based web application
- OpenAI API integration
- Secure API key management using `.env`

## Technologies Used

- Python
- Flask
- OpenAI API
- HTML
- CSS
- JavaScript
- python-dotenv

## Project Structure

```text
AIAssistence/
│
├── app.py
├── templates/
├── static/
├── .env
├── .gitignore
└── README.md
```


## Run the Application

```bash
python app.py
```
